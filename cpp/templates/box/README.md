# Class template `Box<T>` lab

A minimal class-template exercise centered on value ownership and const-correct accessors.

## Focus

- class-template instantiation;
- pass-by-value construction followed by move into storage;
- mutable and const accessor overloads.

## Run

```bash
cmake --build --preset dev --target class_template_box_lab
./build/dev/cpp/templates/box/class_template_box_lab
```
