# Fold expressions lab

A variadic-template lab for unary/binary left and right folds.

## Focus

- parameter packs;
- sum and logical folds;
- comma folds for repeated side effects;
- left-vs-right associativity with subtraction.

## Run

```bash
cmake --build --preset dev --target folds_lab
./build/dev/cpp/templates/folds/folds_lab
```
